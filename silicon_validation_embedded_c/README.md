## Learning Path (5 Months)

```
Month 1  →  Chip flow + C language deep dive
Month 2  →  UVM / SVA / Formal verification
Month 3  →  IP test plans (CAN, SPI, I2C, USB, DDR)
Month 4  →  Post-silicon bring-up + RTOS + MISRA
Month 5  →  CI/CD pipeline + 60 interview Q&A
```

## Key Topics Covered

- Pre-silicon validation: UVM testbench, coverage, assertions, formal verification
- Emulation: Cadence Palladium Z1/Z2, Synopsys ZeBu, ICE, SCE-MI
- Post-silicon: silicon bring-up checklist, JTAG, MBIST, characterisation, AEC-Q100
- IP test plans: CAN FD, I2C, SPI, UART, USB 2.0, DDR4/LPDDR4
- Embedded C: volatile, memory-mapped registers, FSM, ring buffer, memory pool
- RTOS: FreeRTOS tasks, semaphores, mutexes, ISR-safe APIs
- MISRA C:2012: rules, rationale, static analysis setup
- Unit testing on host: Unity framework, hardware abstraction for testability
- Requirements engineering: SMART requirements, traceability matrix
- CI/CD: GitHub Actions for embedded C (build, test, coverage, MISRA)
