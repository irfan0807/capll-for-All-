# Python DSA Categories

The runnable entry files are grouped by algorithm pattern:

- `arrays/`: list traversal, merging, rotation, missing values, and in-place array operations.
- `strings/`: string comparison, parsing, reversal, anagrams, and substring exercises.
- `searching/`: binary search and pair-sum searches.
- `sorting/`: sorting algorithms.
- `math/`: numeric, percentage, Armstrong-number, and Fibonacci exercises.
- `hash_maps/`: duplicate and frequency lookup problems.
- `two_pointers/`: container and rain-water pointer techniques.

The original Desktop source files remain in the parent `dsa/` directory so their learning examples are preserved unchanged. Each categorized file is a runnable entry point for its matching original.
