## 💡 KEY NUMBERS TO MEMORIZE

These will be asked in interviews:

### **CAN**
- Classical CAN max payload: **8 bytes**
- CAN FD max payload: **64 bytes**
- Max CAN ID: **0x7FF** (11-bit) or **0x1FFFFFFF** (29-bit)
- Max CAN bit rate: **1 Mbit/s**
- CAN FD data phase max: **8 Mbit/s**
- CAN error active threshold: **128**
- CAN error passive threshold: **256**
- Bit stuffing rule: **After 5 identical bits, insert 1 opposite bit**

### **CAN-TP**
- Max single frame payload: **7 bytes** (11-bit CAN) or **6 bytes** (29-bit)
- Max first frame payload: **6 bytes** (11-bit) or **5 bytes** (29-bit)
- Max consecutive frame payload: **7 bytes**
- Max PDU size: **4095 bytes** (classical CAN-TP)

### **LIN**
- Max payload: **8 bytes**
- Bit rate: **9.6, 10.4, 19.2 Kbit/s**
- Master: **1 per network**
- Slaves: **1-15 per master**

### **Test Levels**
- **Unit test:** Single function, no ECU
- **Component test:** One software component
- **SW integration:** Multiple components together
- **SW-SW integration:** Multiple ECUs over CAN/LIN
- **HW-SW integration:** Real hardware + real software
- **System test:** Complete system (HIL simulation)
- **Vehicle test:** Real vehicle
