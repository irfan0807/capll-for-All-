## PRIORITY CLASSIFICATION

### 🔴 CRITICAL (Must Know - 100% Asked)
**If you know nothing else, know these.**  
**These will be asked in EVERY interview.**  
**No exceptions.**

#### CAN Protocol (Part 6) - 6 hours
- Arbitration mechanism
- Frame structure and decoding
- All 5 error types
- Bus-off state and recovery
- Bit timing concepts

**Why:** Every automotive interview starts with CAN  
**Interview odds:** 100%  
**Typical questions:**
- "Explain CAN arbitration"
- "What are the 5 error types?"
- "How do you decode this CAN frame?"
- "What causes bus-off?"

---

#### Test Levels (Part 3) - 5 hours
- Unit, Component, Integration, System, Vehicle
- Scope, cost, speed of each level
- When to use each
- Defect detection at each level

**Why:** Defines your job scope  
**Interview odds:** 100%  
**Typical questions:**
- "Describe all test levels"
- "Where would you find XYZ defect?"
- "Why do we need 7 test levels?"

---

#### Test Case Design (Part 5) - 5 hours
- Boundary Value Analysis
- Equivalence Partitioning
- Test case format and structure
- Positive vs Negative testing
- Decision tables

**Why:** Core skill - you write 100+ test cases  
**Interview odds:** 100%  
**Typical questions:**
- "Design test cases for this requirement"
- "Describe your test design approach"
- "What's the difference between BVA and Equivalence?"

---

#### Requirement-Based Testing (Part 4) - 4 hours
- Requirement to Test flow
- Identifying bad requirements
- Requirement traceability
- Requirement analysis

**Why:** Foundation of all testing  
**Interview odds:** 90%  
**Typical questions:**
- "How do you test a requirement?"
- "What makes a requirement untestable?"
- "What's requirement traceability?"

---

#### Python Basics for Automation (Part 15) - 5 hours
- Python fundamentals
- OOP concepts
- File I/O, JSON, CSV
- CAN libraries (python-can)
- pytest framework

**Why:** Job requires Python scripting  
**Interview odds:** 95%  
**Typical questions:**
- "Write a Python script to send CAN messages"
- "How do you structure a test framework?"
- "What Python libraries have you used?"

---

#### UDS Diagnostics (Part 10) - 4 hours
- UDS services (0x10, 0x11, 0x19, 0x22, 0x27, 0x2E)
- Diagnostic sessions
- Security access
- Negative response codes

**Why:** Diagnostics are essential for testing  
**Interview odds:** 85%  
**Typical questions:**
- "What is UDS and why is it important?"
- "Explain this UDS request"
- "What's a negative response code?"

---

#### Debugging Methodology (Part 19) - 4 hours
- Structured debugging approach
- Root cause analysis
- Using logs effectively
- Common defect types

**Why:** You'll spend 40% of job debugging  
**Interview odds:** 90%  
**Typical questions:**
- "Describe a defect you found and debugged"
- "Walk me through your debugging process"

---

#### Your Own Project Experience (Self-Created) - 3 hours
- STAR format (Situation, Task, Action, Result)
- 3-5 strong project stories
- Metrics and achievements
- Real problems you solved

**Why:** Behavioral/experience questions in every interview  
**Interview odds:** 100%  
**Typical questions:**
- "Tell me about your most complex project"
- "Describe a time you solved a difficult problem"
- "What's your proudest achievement?"
